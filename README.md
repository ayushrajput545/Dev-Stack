# Dev Stack - Online Code Editor

## Overview
Dev Stack is an online community and platform designed for front-end developers to showcase their HTML, CSS, and JavaScript code snippets. This application allows users to create and manage their projects seamlessly.

### Tech Stack
- **Frontend**: React.js, Tailwind CSS
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **API Testing**: Axios
- **Authentication**: JWT, bcrypt

## How to Use
1. **Sign Up**: Create your account by signing up.
2. **Login**: Access your account using your username and password.
3. **Create Project**: Start a new project.
4. **Start Coding**: Click on your project to begin coding.

**Note**: You can start coding without signing up!
